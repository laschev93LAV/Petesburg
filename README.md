# A page about the city of St. Petersburg.

- Учебный проект посвященый городу Санкт-Петербургу.
- Создана с нуля на HTML и CSS \

## Демо

[Открыть проект](https://laschev93lav.github.io/Petesburg/)

## Стек

- HTML5 (семантическая верстка)
- CSS3 (Flexbox, CSS-переменные)
- Адаптивная верстка
- Анимации.

## Что внутри 

- 'index.html' - главная страница
- 'styles.css' - стили
- 'images/' - изображения для страницы

## Что реализовано 

- Семантическая верстка (`<header>`, `<main>`, `<article>`)
- Карточки на Flexbox и Grid
- Фиксированая шапка
- Кнопка 'наверх' с плавным скроллом
- Mobile-first
- Адаптиность под разные устройства
